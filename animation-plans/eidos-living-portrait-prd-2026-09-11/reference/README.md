# Reference inventory

All files in this directory are inputs or private production references. They are not automatically approved for public deployment.

## Brand

- `brand/hero-desktop-master.png`: current approved Faun and Gryphon composition. Use as character and paper reference, not as a requirement to keep both characters in the new hero.
- `brand/hero-mobile-master.png`: current mobile source composition.
- `brand/faun-mark.webp`: navigation-scale Faun source.

Faun must be extracted or restored from these exact sources. Do not generate a replacement Faun.

## Peakstarwave

- Four supplied one-second motion references.
- `peakstarwave-contact-sheet.jpg` shows eight sampled frames from each clip.

Use them only for discrete frame rhythm, fixed-subject hierarchy, hard printed re-composition and color-plate collisions. Do not reuse creator imagery in the final product and do not copy the horses, peacock, tiger, blue silhouettes, test-sheet text or exact layouts.
