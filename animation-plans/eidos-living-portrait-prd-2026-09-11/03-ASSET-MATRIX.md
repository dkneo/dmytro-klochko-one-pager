## Production order

1. Approve the desktop storyboard as a still.
2. Build the desktop runtime composition with exact sources.
3. Verify the artwork remains large, the first paint is complete and the mask holds at all widths.
4. Compose mobile separately and verify at 390px.
5. Build keep, pass and undo.
6. Build the delayed loader and absolute favorite response.
7. Add Gryphon only to provenance and map.
8. Run motion, accessibility, performance and interruption checks.

No share card, completion movie or ambient hero loop is P0. Add them only after the product surfaces pass.
