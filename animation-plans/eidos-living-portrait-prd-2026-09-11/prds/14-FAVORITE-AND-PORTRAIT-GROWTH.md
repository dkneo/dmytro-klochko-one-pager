# UI-04: absolute favorite

## Purpose

Absolute favorite is rare enough to earn one richer response. It does not move the painting into a collection slot. The work stays large while Faun receives a second ink pass.

## Trigger

Mark the control immediately. Start the ink response only when persistence succeeds. Never delay the next artwork.

## Timeline

| Time | Event |
| ---: | --- |
| 0 to 110ms | control presses to `scale(.97)` and returns |
| 110 to 230ms | a baby-pink Faun plate takes color from the active work |
| 230 to 320ms | exact graphite key lands 2px out of register, then catches |
| 320 to 410ms | richer registered state resolves once |
| 410 to 500ms | next work is already present; the small Faun mark keeps one pink key line |

Use no star, heart, confetti, sparkle, badge flight, thumbnail clone or mascot acting.

## Undo

Remove the persistent pink key from the control in 120ms. Do not play the ritual backward. Restore the verdict and work independently.

## Reduced motion

Press the control for 100ms and apply the persistent pink key immediately.

## Acceptance

- the active art remains the largest object for the entire response;
- the next work is usable within 220ms even while the rare response resolves elsewhere;
- repeated input retargets without queuing;
- the result reads as richer printing, not celebration graphics.
