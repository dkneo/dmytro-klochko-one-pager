# Reference audit

## Verdict

The Peakstarwave set is an excellent behavioral reference and an incomplete visual reference.

- Core mechanism: `9/10`
- Literal palette and graphic language for Eidos: `5/10`
- Suitability for smooth image-to-video generation: `2/10`
- Suitability for frame-built stop motion: `10/10`

The previous Eidos animation pack failed because it generated little movies. This reference succeeds because it behaves more like a stack of printed stills.

## Clip-by-clip reading

| Reference | Strong | Weak | Use |
| --- | --- | --- | --- |
| `peakstarwave_2070508838910914911.mp4` | The animal remains a simple fixed read while marks change rapidly | Marker blobs become childish and arbitrary; empty white field has little depth | Borrow only the fixed-subject principle |
| `peakstarwave_2095935195467706785.mp4` | Calibration bars and overprinting create a convincing process language | Literal CMYK furniture feels like a design-school exercise and competes with the horse | Borrow the layered printing rhythm, not the charts |
| `peakstarwave_2096600209778159861.mp4` | Strongest composition; the long peacock silhouette holds the frame while each field reorganizes | Cyan peacock and technical charts are wrong for Eidos; every frame is equally loud | Primary reference for hierarchy and shape continuity |
| `peakstarwave_2098225758522970202.mp4` | Best color collisions and most energetic re-compositions | Tiger plus rainbow blocks can drift toward children's editorial illustration | Borrow the color overlap and pacing in small doses |

## What Eidos borrows

1. One unmistakable creature remains visually constant.
2. Color and key plates register in a tactile sequence.
3. Small misregistration makes the print feel physical.
4. Motion is graphic and tactile, not cinematic.
5. The sequence can be understood from any single frame.

## What Eidos replaces

| Reference language | Eidos translation |
| --- | --- |
| Generic marker scribble | One exact kept artwork, still identifiable |
| CMYK test bars | One baby-pink plate and one rare orange registration point |
| Random printer text | Live artist, title and year from the real record |
| Blue animal silhouette | Exact graphite Faun source |
| Full-frame visual noise | One artwork field and one Faun key plate |
| Continuous one-second loop | One state-driven registration, followed by complete stillness |

## The essential insight

The animation should not say, “our mascot is alive.” It should say, “your portrait is still being printed from the things you choose.”
